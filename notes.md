# What is a State Variable?

a variable that holds a state is a variable that 
controls how your application should behave based on 
what it is holding.




# Better definition:

A state variable is variable that holds data representing 
the current condition of your application (or a part of it), 
and changes to that variable cause the application (or UI) 
to update/behave differently in response.
